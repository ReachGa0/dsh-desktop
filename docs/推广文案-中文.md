## 正文

最近 DeepSeek 官方出了个 DeepSeek Harness（dsh），是个挺强的本地 Agent 工作台，但使用方式要开终端敲命令、再切浏览器，日常用起来有点繁琐。

于是我用 Electron 给它套了个壳：**[dsh-desktop](https://github.com/ReachGa0/dsh-desktop)**

双击图标 → 自动拉起 dsh web 服务 → 独立窗口直接使用。不用开终端、不用敲命令、不用切浏览器。

**几个我觉得不错的设计：**

- 🧠 **智能复用**：检测到 3080 端口已有 dsh 服务就直接复用，不会重复启动
- 🧹 **干净退出**：关窗口只杀自己启动的进程树，绝不误杀你手动起的服务
- 🔒 **单实例锁** + 安全加固（contextIsolation / sandbox / 无 Node 集成）
- 📦 **一键打包**：`npm run dist` 直接出 NSIS 安装包
- 🔧 **端口可换**：3080 被占时 `npm start -- --port 3081` 就行

**纯壳，零侵入**：不改 dsh 任何代码，服务端复用你全局装的 `@deepseek-ai/dsh`，升级 dsh 壳不用动。

代码很少（就两个文件），MIT 协议，欢迎提 Issue / PR / star ⭐

https://github.com/ReachGa0/dsh-desktop
