## 正文

最近 DeepSeek 官方出了个 DeepSeek Harness（dsh），是个很强的本地 Agent 工作台，但使用要开终端敲命令、再切浏览器，日常用起来有点繁琐。而且 dsh 是纯文本模型，**看不了图**。

于是我给它做了个 **Electron 桌面版**：**[dsh-desktop](https://github.com/ReachGa0/dsh-desktop)**（Windows）

双击图标 → 自动拉起 dsh web → 独立窗口直接使用。不用开终端、不用敲命令、不用切浏览器。

**最大的亮点：📸 选区截图直接提问**

- 点一下截图按钮 → 全屏遮罩**实时框选**（GPU 加速，画完还能拖 8 个手柄微调，微信截图同款体验）
- 截图自动粘贴进聊天框 → 配合 ModLens 等识图插件，**纯文本的 DeepSeek 也能看懂图**
- 报错代码截个图、网页截个图、文档截个图，直接问，不用复制粘贴

**其他功能：**

- 🗂️ **会话管理**：`Alt → 文件 → 会话管理` 一键删除不要的会话
- 🍱 **系统托盘**：关窗口最小化常驻，右键退出
- 🧭 **环境自动引导**：首次启动自动检测 Node/dsh，缺啥一键装，小白友好
- 🔄 **便捷刷新**：F5 / Ctrl+R / 悬浮按钮，装新插件不用重启
- 🔧 **端口可换**：`npm start -- --port 3081`

**纯壳，零侵入**：不改 dsh 任何代码，服务端复用全局 `@deepseek-ai/dsh`，升级 dsh 壳不用动。MIT 协议，欢迎提 Issue / PR / star ⭐

https://github.com/ReachGa0/dsh-desktop
