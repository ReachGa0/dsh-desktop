# dsh-desktop 使用说明（分享给朋友用）

## 这是什么

DeepSeek Harness 的桌面版（Electron 壳）：双击图标就能用，不用开终端、不用敲命令、不用切浏览器。
它本身只是"外壳"，真正干活的是 DeepSeek 官方工具 dsh + 你的 DeepSeek API Key。

## 安装步骤（约 10 分钟）

### 第 1 步：装 Node.js
去 https://nodejs.org 下载 **LTS 版**（22 或 24 都行），一路下一步安装。

### 第 2 步：装 dsh（DeepSeek Harness 命令行工具）
打开 PowerShell，运行：
```powershell
npm install -g @deepseek-ai/dsh
```
验证：
```powershell
dsh --version
```

### 第 3 步：安装 dsh-desktop
去 https://github.com/ReachGa0/dsh-desktop/releases/latest 下载最新版安装包（`dsh-desktop-0.2.8-setup.exe`），双击按向导安装。

### 第 4 步：配置 API Key
1. 打开 DeepSeek 开放平台：https://platform.deepseek.com → 注册/登录
2. 充值（API 按量付费，很便宜）
3. 创建 API Key（复制，形如 `sk-...`）
4. 打开 dsh-desktop → **设置 → 模型** → 填入 API Key

### 第 5 步：开始使用
选择你的工作文件夹，就可以和 AI 对话了（写代码、处理文件、搜资料都行）。

## 常见问题

- **打开就报错**：确认 `dsh --version` 能输出版本号；日志在 `%APPDATA%/DeepSeek Harness Desktop/dsh.log`
- **关窗口没退出**：正常！它最小化到系统托盘（屏幕右下角），右键托盘图标选"退出"
- **提示 API Key 无效**：检查 Key 是否完整复制、账号是否已充值
- **端口被占用**：用 `npm start -- --port 3081` 换端口（源码运行方式）
